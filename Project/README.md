# Phonebook (AVL Tree)
A simple console phonebook in C++ using an AVL tree

## Build & Run
g++ phonebook.cpp -o phonebook
./phonebook

## Menu
1. Add
2. Search
3. Update
4. Delete
5. Display all
6. Save and Exit

## Contact Fields
Name, Country code, Phone, Email, City

## Storage
Saved to `phonebook.txt` on exit and loaded on start.
